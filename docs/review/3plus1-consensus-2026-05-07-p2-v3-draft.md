## 3. 추가 점검 항목 (Reviewer 자기 발견)

본 §3은 사용자 명시 7 기준 외 Reviewer가 자기 발견한 잠재 위험 항목.

### 3.1 P-1 — §9.2 "권고 옵션 A" 표현 (소프트 관찰)

**위치**: 본 초안 §9.2 다음 옵션 표 아래 단락:
> "**권고 옵션** (사용자 결정 후보, 본 초안은 *권고 단정 금지*): 옵션 A. 사유: G1b PASS evidence는 이미 권위 확정 (R-7 SOP §7.3 단축 합의), 본 v3는 그 결과를 P2 본문으로 흡수하는 작업. 새 설계 안건 없음. 단, 옵션 B / C 도 사용자 결정 시 정당."

**관찰**:
- 본 단락은 "권고 단정 금지" 자기 hedge 포함 + "B/C도 정당" 명시 → 강요 아님
- 그러나 사용자가 *실제로 채택한 결정*은 **A-변형** (DRAFT 커밋만, 정식 채택 보류) — 본 §9.2 옵션 A/B/C 어디에도 매핑되지 않음
- 옵션 A 본문은 "단축 합의 → v3 정식 채택 → ADR PR 묶음 → INDEX/CONTEXT 갱신"으로 *전체 정식 채택 경로* 의미. A-변형은 그 중 첫 단계만

**위험 등급**: 낮음 (LOW)
- 사용자가 이미 A-변형 결정함 → 미래 의사결정 영향 없음
- DRAFT 상태 자체가 "본 초안은 미완"을 표시
- "권고 단정 금지" hedge 명시

**권고 처리**: BLOCK 사유 아님 / APPROVE WITH REVISIONS 의무 아님. 본 검토 후속 작업 시 §9.2에 **A-변형 옵션 추가** 권고 (DRAFT 커밋 → G2/G3/G4 → 정식 채택 → ADR PR 묶음 → archive 처리). 본 추가는 *정식 채택 시점 또는 G2/G3/G4 작업 도중* 어느 시점이든 가능.

### 3.2 P-2 — §1.5 carry-over에 §3 Phase 0 / §4 Phase 1 본문 갱신 항목 명시 (확인 사항)

**위치**: 본 초안 §1.5:
> "§3 Phase 0 ~ §6 Phase 3 단계 정의 (단, **§3 Phase 0의 R-1 결과**는 본 v3 §3.2 G1a FAIL로 갱신)"

§8 carry-over 매핑 표:
> "§3 Phase 0 | §3 | 변경 없음 (단, **R-1 결과**는 본 v3 §3.2 G1a FAIL로 갱신)"
> "§4 Phase 1 | §4 | 변경 없음 (단, **차단조건 #1 exit**는 본 v3 §3.3 G1b PASS로 갱신)"

**관찰**:
- §1.5는 "carry-over (변경 없음)"으로 명시하면서 동시에 "단, R-1 결과는 갱신"이라는 *반(半) 갱신* 표현. 모호.
- §8 carry-over 매핑은 "변경 없음" + 괄호 내 갱신 사항 명시 — 일관성

**위험 등급**: 낮음 (LOW)
- 본 초안이 v2 본문 자체를 *재서술하지 않는다*는 의도는 명확
- 갱신 사항은 *cross-reference*만 추가하는 의미로 읽힘 (§7 ADR 매트릭스 절차와 동일 패턴)

**권고 처리**: BLOCK 사유 아님 / 정식 채택 합의 시 §1.5와 §8 표현 통일 권고 ("v3 본문이 carry-over 본문을 *재서술하지 않으나*, 본 v3 정식 채택 시 v2 §3 / §4의 R-1 결과 / 차단조건 #1 exit 부분에 *cross-reference 주석*만 추가").

### 3.3 P-3 — §9.2 옵션 A 사유 "새 설계 안건 없음" 표현 (확인 사항)

**위치**: §9.2:
> "사유: G1b PASS evidence는 이미 권위 확정 (R-7 SOP §7.3 단축 합의), 본 v3는 그 결과를 P2 본문으로 흡수하는 작업. **새 설계 안건 없음**."

**관찰**:
- 본 v3 §4 / §5 / §6 (G2 / G3 / G4 정의 + entry/exit 기준 + 산출 후보 + 의존 ADR) 은 *새 설계 안건* 으로 분류 가능
- "새 설계 안건 없음" 표현은 G2/G3/G4 *PASS* 가 아니라 *정의* 자체도 새 설계로 보지 않는다는 해석 — 단축 합의 정당화 문맥에서

**위험 등급**: 낮음 (LOW)
- 본 v3 §4 / §5 / §6 은 *후보 명세*이며 *권위 결정*이 아님 → 단축 합의 적격
- 그러나 *완전히 새 설계 안건 없음*은 과장. 차라리 "evidence 흡수가 핵심이며, G2/G3/G4 정의는 후보 명세 한정"으로 표현 권고

**권고 처리**: BLOCK 사유 아님 / 정식 채택 합의 시 표현 정밀화 권고.

### 3.4 P-4 — §2.6 격상 7단계의 단계 5 "통합 검증 합의(풀 3+1)" 강제 (확인 사항)

**권고 처리**: BLOCK 사유 아님 / 보존 권고. 단, G2 / G3 / G4 각각의 PASS 합의 형태(단축 vs 풀)는 G2/G3/G4 작업 시점에 별도 결정 — §4.3.2 / §5.4.2 / §6.4.2 모두 "단축 합의 또는 풀 3+1 합의 APPROVE"로 양쪽 가능 명시. 일관.
