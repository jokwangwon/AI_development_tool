## 3. 불일치 (Divergence) + 판정

**D1. MVP-0 첫 진화 대상 — C "프롬프트/설정(벤치마크 센서, 자동 적용+자동 revert)" vs codex "메모리/사용자 모델(사용자 승인 게이트)"**

판정: **이중 트랙 병행 채택 — 게이트가 다른 두 표면.**

| 트랙 | 대상 | 게이트 | 비전에서의 역할 |
|---|---|---|---|
| **M (동반)** — codex 채택 | 메모리/사용자 모델 (선호·규칙·패턴·실패 사례 추출→구조화 후보) | **사용자 승인** 항목만 반영 | "사용자와 **함께**" — 동반 성장의 체감 가치, rollback 쉬움, 보안 단순 |
| **E (진화)** — C 채택 | 프라이데이 자기 프롬프트/설정 (F-0) | **고정 벤치마크 스위트 점수** — 하락 시 자동 revert | "**발전**" — Layer 3 자동 적용의 최소 실증. ADR-011 §2.1 (b) 격리 PoC + (d) 자동 회귀 검증을 한 바퀴로 동시 산출 |

근거: 사용자 비전 "AGI로서 사용자와 **함께 발전**"은 양방향이다. codex 트랙만 택하면 사용자 승인 게이트 때문에 D-2 (R)의 실질(자동 적용 자격 실증)이 산출되지 않고 — 자비스 Layer 0/1이 이미 끝낸 "제안만" 단계의 반복이 된다(C 발견 #7). C 트랙만 택하면 동반 성장의 체감 가치가 벤치마크 점수로 축소된다. 두 표면은 겹치지 않고(메모리 vs 자기 프롬프트), 둘 다 코드 수정이 아니어서 C-6을 보존하며, C의 F-0b는 1–2 cycle 규모라 1인 부담상 병행 가능. codex 스스로 "프롬프트는 자동 변경 말고 제안서까지"라 했으나 이는 벤치마크 센서+자동 revert 부재를 전제한 보수성 — C의 계산적 센서가 그 전제를 제거한다. 순서: F-0a 뼈대(진화 0) → M/E 병행.

**D2. R-Friday-3 "제안 포함" trigger — C "과잉, 강등" vs B "유지"**

판정: **B 채택(유지) + 범위 정밀화.** C의 강등 논리는 제안 일반에는 옳지만, R-Friday-3의 대상은 **자비스 본문/거버넌스 변경 제안**에 한정된다 — 자비스 개선은 프라이데이의 존재 이유가 아니다(존재 이유 = 자기 진화). codex도 독립적으로 "자비스 변경 제안도 못 하게 하는 권위 분리 유지"를 6대 조건에 넣었고, 이 trigger는 B가 규명한 사회공학 경로(사용자 손을 거친 반입)의 **유일한 사전 센서**다. 발생하지 않으면 비용 0이므로 비례성 문제도 없다. 정밀화 명문: **발화 대상 = "자비스 스코프 변경 제안"에 한정, 프라이데이 자기 개선 제안의 사용자 표시 = 비발화** — 이 정밀화로 C의 우려(학습 산출물 억압)는 전부 해소.

**D3. 진입 cadence — `/loop` self-paced vs 이산 cycle (C의 (T) 흡수)**

판정: **이산 cycle 채택.** 근거 수렴이 압도적: C(evidence 경계 명확·R-Friday-5 비용 통제·세션 상주 비용 회피), B(R-Friday-6 루프 폭주 축 — self-paced 무감독 반복이 동일 구독의 자비스 작업까지 차단), A(컨텍스트 소진 실패 모드 — 장기 `/loop`는 compaction으로 루프 상태 소실). 사용자의 기존 워크플로 메모리(단계별 합의 cycle, 자동 다음 단계 진입 금지)와도 정합. A의 **루프 상태 파일 외부화(JSONL) 의무는 cadence와 무관하게 유지**(이산 cycle에서도 주기 간 상태는 파일이 유일한 연속성).

**D4. Landlock/가짜홈 vs codex "별도 Unix user" — 비례성 판정**

판정: **가짜홈+Landlock 채택, 별도 Unix user = DEFER(트리거 명시).** codex가 나열한 우회 경로 대부분(`~/.ssh`·gitconfig·credential helper·Claude 설정/토큰·shell history·환경변수 유출)은 자비스가 이미 실증한 **레벨 2 가짜 홈(HOME 재배치+env allowlist+RO 최소화, ADR-014)이 정확히 막는 것들**이다 — codex는 이 실증 사실을 모르는 외부 시각이라 신규 설계로 권고했을 뿐, 위협 목록 자체는 유효하고 해법은 기보유. 별도 Unix user는 관리 비용(권한·GPU 접근·파일 교환·gpu_lock flock 공유) 대비 한계 이득이 낮아 solo 개인 툴 비례성상 과잉. **DEFER 발효 트리거**: (i) 프라이데이가 네트워크 egress 능력을 획득하거나 (ii) 무인 장기 상주(daemon화)로 전환되는 시점. 단 codex 목록 중 가짜홈이 못 막는 2건 — **symlink escape, backup/인덱서 동시 스캔(P-4로 같은 부모라 더 현실적)** — 은 codex의 "allowlist 접근 smoke test + symlink escape 테스트" 권고로 흡수(선결 조건 8).

## 8. 비전 정직 프레이밍 합의문

사용자 비전("AGI로서 사용자와 함께 발전하는 인공지능")을 북극성으로 보존하면서 over-claim을 구조적으로 회피하는 합의 문안 (brief 서두 채택 권고):

> **프라이데이는 "사용자와 함께 발전하는 AGI"를 북극성으로 삼는다 — 단 이것은 도달의 주장(claim)이 아니라 방향(vector)이다.** 현재의 프라이데이는 AGI가 아니며 AGI임을 주장하지 않는다. 프라이데이는 AGI적 속성 — 지속성, 자기반성, 도구 사용, 장기 기억, 사용자 적응 — 을 개인 로컬 환경에서 격리된 채 실험하고, 검증 가능한 개선만 누적하는 **동반 성장 지능 프로토타입**이다. "함께"는 사용자 승인 게이트(메모리 트랙)로, "발전"은 계산적 적합도 센서와 자동 revert(진화 트랙)로 구현된다. Claude는 후보 생성자이자 부트스트랩 엔진일 뿐 root of trust가 아니다. 프라이데이는 런타임에서 로컬로 자라며 — 언젠가, 스스로 큰다.
