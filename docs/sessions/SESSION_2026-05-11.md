## 3. P-3 흡수 — §4.3 / §4.5 import schema_version 절차 정밀화

### 3.1 흡수 위치

- **§4.3 #3 행 보강**: schema_version 호환성 행에 `T2 사용자 승인 + §10.2 합의 절차 + §4.5.3 import 검증 절차 통과 의무` cross-reference 추가
- **§4.3 §말미 P-3 흡수 완료 표기**: 흡수 요지 + 본 절차 충족 *전* import = BLOCK 명시
- **§4.5.2 사양 요건 보강**: schema_version 명시 의무 강화 + `--declare-schema-version <version>` flag 신설 + canonical JSON RFC 8785 의무 명시 + 라운드트립 검증 Tier-based cross-reference
- **§4.5.3 신설 (Import 시 schema_version 검증 절차 — P-3 흡수)**: Step 1~4 정밀 절차 본문화
- **§4.6.5 Import 의무 검증 보강**: §4.5.3 정밀 절차 cross-reference 추가 + Step 5 ledger entry 의무 추가

### 3.2 §4.5.3 Step 1~4 정밀 절차

- **Step 1 — `schema_version` 필드 존재 확인**: 필드 부재 = 즉시 BLOCK + `event: import_block_missing_schema_version` ledger entry + 사용자 명시 manual review (자동 default 부여 금지 — T3 위반)
- **Step 2 — `schema_version` 호환성 매트릭스 조회**: 일치 → Step 3 / MINOR 호환 → Step 3 + `event: import_compat_minor` ledger entry / MAJOR 비호환 → BLOCK + Step 4
- **Step 3 — schema validation + canonical JSON 재해석**: §4.6.5 #4 + §4.4.2 답습 + hash chain 검증 + 검증 통과 → import 허용 + `event: import_pass` ledger entry / 실패 → BLOCK + `event: chain_violation_detected`
- **Step 4 — 비호환 `schema_version` Declaration 절차 (T2 사용자 승인)**: (1) `--declare-schema-version` flag 또는 별도 합의 보고서 (2) MINOR → 단축 합의 (Reviewer-only) / MAJOR → 풀 3+1 + ADR Amendment (3) 호환성 매트릭스 갱신 (Implementation PASS 영역) (4) `event: schema_version_declared` ledger entry (5) `event: import_pass_after_declaration` 또는 `event: import_block_after_declaration`

### 3.3 §4.5.3 금지 사항 (T3 영역)

- ❌ schema_version 자동 default 부여 (필드 부재 시)
- ❌ schema_version silent drift (Hermes-originated 변경 — G3 §6.4 답습)
- ❌ 비호환 `schema_version` 자동 import (사용자 명시 declaration 없이)
- ❌ Step 1~3 통과 ledger entry 부재 상태에서 PASS 선언 (G3 §1.3 + §5.3 답습)

### 3.4 §4.5.3 본 §가 *하지 않는* 것

- ❌ 호환성 매트릭스 *내용* 자동 생성 (현 MVP `0.1` only — 외부 형식 매핑 = 별도 합의)
- ❌ 실 import 코드 구현 (Implementation/Runtime PASS 영역, §4.6.7 답습)
- ❌ 자동 declaration 발급 (T3 위반)
- ❌ Hermes 자기 declaration 발급 (G3 §6.4 + §2.2 #18 답습)

### 3.5 P-3 흡수 *범위 한계*

- ✅ §4.3 / §4.5.2 / §4.5.3 / §4.6.5 본문 정밀 절차 *사양* 본문화
- ❌ 실 import 코드 구현 = Implementation/Runtime PASS 영역 별도 합의 (§4.6.7 답습)
- ❌ 호환성 매트릭스 *내용* (외부 형식 매핑) = 별도 합의
