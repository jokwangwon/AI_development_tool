# SESSION 2026-05-22 — credential 수단 발효 시도 → 비례성 DEFER

> 사용자 진입: "credential 수단 발효로 진행 (4축 통합 정리 §7.4 권고 진입 경로 step 1) — 실제 host OS 확인 → TPM/SE/YubiKey 가능한 것 → 수단 결정 + 백업키 정책 검토."

**credential 서명 격리 발효를 시도했으나, cascading 3+1을 거쳐 "개인 툴엔 비례 초과"로 발효 전체 DEFER. DESIGN 청사진 보존.** 부산물로 harness 일반 권한 정책 **P-PRIV** 확정.

## 핵심 발견

- **SW-1 ⭐⭐ (3+1이 키 생성 전에 잡음)**: TPM+PIN backstop은 **root-동치 host(delangi=docker+sudo)에서 거짓** — root가 ptrace/메모리 scrape/pinentry hook으로 PIN 탈취. **PIN=메모리 진입 ≠ YubiKey 물리 터치=메모리 미진입.** 합의 CMA-2(touch=유일 방어)를 워크플로우 층위에서 재확인 → 수단 재고 YubiKey.
- **⭐⭐ 비례성 (사용자 제기)**: solo·single-host·**본인용 개인 개발 툴**에 하드웨어 서명·touch-per-commit·서명 사용자는 실 위협 모델(에이전트 실수·공급망 = review/test/git로 충분)에 **비례 초과**. "내 머신에 root 잡은 공격자"는 이미 게임 끝 → 서명 격리 한계이득 0. **means/ends(ADR-011): 하드웨어 서명=MEANS, 현 비용>이득.**
- ⚠️ 거짓 안전감의 역(逆): 적용 안 되는 위협에 보안 극장 짓는 것도 실패 양식 — 이를 사용자가 포착.
