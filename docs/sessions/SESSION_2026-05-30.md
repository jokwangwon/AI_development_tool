### 사용자 통찰 (v1.2, IN-1/IN-2) — "사장이 직원보다 똑똑하다고 할 수 없다"
- 현 구조: boss=`OllamaBoss`(로컬, 약함) vs worker=`CliWorker(claude/codex)`=frontier 가능 → **직원이 더 똑똑할 수 있음**.
- **boss 가치 = 똑똑함이 아니라 통제 위치**(로컬 상주 + provider-agnostic 조율). plan-then-execute 정당화는 "사장이 똑똑해서"가 아니라 "약하니까 제어권 박탈, 제안만".
- **plan 공급원 유연**: `boss.plan()`은 공급원 중 하나일 뿐. 사람/frontier worker 도 가능. **PLAN-SOURCE 불변식 = 똑똑함≠신뢰**: 누가 짠 plan 이든 controller 검증 + 사람 승인(frontier 도 untrusted).
- 구현 반영: `BossPlanner` Protocol 을 `advise`(BossLLM)와 *분리* → plan 공급원이 boss 로 고정되지 않는 구조.
