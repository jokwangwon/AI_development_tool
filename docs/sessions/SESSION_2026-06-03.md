## 핵심 기술 여정 (연구→실측→구축)

### 1. 패러다임 전환 식별
현 `jarvis_hud/plugins/tts_compare`(F5-TTS-ko 흉내/복제) ≠ 목표(speaker generation, 새 화자).
사용자 목표 = 복제 아닌 **생성**, 한국어, 캐릭터별 보이스, 권리 자유.

### 2. 연구 (deep-research + 한국어 특화 병렬)
- speaker generation(잠재공간 새 화자 샘플링)은 학술적 타당(TacoSpawn·VoxGenesis). 단 코드·
  체크포인트 없음 + 영어 전용 → 한국어 R&D.
- ⭐ 최대 리스크 = **GB10 aarch64+Blackwell 호환성**(연구는 미해결). 한국어 speaker generation 부재.

### 3. GB10 실측 — 호환성 해소
aarch64+CUDA13+**sm_121**, **torch 2.12.0+cu130 네이티브 동작**(matmul·기존 F5-TTS-ko 합성 PASS).
연구의 CUDA12 비관은 outdated.

### 4. 경로1 PoC (XTTS) — 메커니즘 OK, 한계 발견
XTTS v2(ko)로 화자 임베딩 보간·prior 샘플링 → 새 목소리 생성. **단 화자 임베딩 평균화로 강한
성인 편향** — 실제 20대·아동 소스 전부 30~40대로 수렴, 나이 시프트 실패. 성별 제어는 OK.

### 5. ⭐ 모델 물색 → GPT-SoVITS 작동 레시피 확립
최신 TTS 동향 조사 → 상업+한국어+GB10 통과 = GPT-SoVITS(MIT)·CosyVoice2(Apache). **GPT-SoVITS
채택**. ⭐ **작동 레시피 = 충실 복제(나이 보존, 평균화 회피) + aux_ref 톤 융합(새 목소리) + 정확한
전사(또렷함)**. 사용자 청취 확인: 젊은+또렷+새목소리 PASS. ⭐ **실패 교훈**: 참조-전사 정확 매칭
필수(AIHub 아동 발성캐릭터 클립 전사 "고맙다"≠4.5초 → 발음 깨짐).

### 6. Qwen3-TTS 비교 (최신, 2026.1.22)
VoiceDesign = **텍스트 묘사로 새 목소리**(참조 불요). 한국어 명시·Apache. ⭐ **instruct 영어가
한국어 출력 제어에 더 안정적**(한국어 묘사는 성별 오류). GPT-SoVITS(복제·신뢰성) ↔ Qwen3(텍스트
제어) 상호보완.
