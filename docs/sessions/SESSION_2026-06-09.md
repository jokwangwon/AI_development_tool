## ① gen_gate ⑤ — HTTP 계층(`server.py`) + voice_lab 호출 규약 정렬 (commit gen_gate `c8be0df`)

> 기존 3계층(lib/CLI/HTTP) 중 HTTP 미구현분. lib(`gate.generate`) 위 **얇은 어댑터**.

- **핵심 설계 = voice_lab 호출 규약 정렬**: 오케스트레이터(애니메이션앱)가 gen_gate(이미지/3D)와
  voice_lab(음성)을 *같은 패턴*으로 호출하도록 응답 모양을 맞춤.
  - `POST /api/generate {model,prompt,commercial,...opts}` → `{id,file,url,ms,model,modality}`
    (voice_lab `POST /api/generate {text,primary,...}` → `{id,file,url,ms,...}` 와 동형 envelope)
  - `GET /api/models[?modality=&category=&commercial_only=]` → 등급 플래그 목록
    (voice_lab `GET /api/speakers` 대응)
  - StaticFiles `/outputs` 서빙 + `/` 헬스. modality→확장자(image=png, 3d=glb).
- **게이트는 lib 가 집행**(HTTP 우회로 없음): LicenseError→403, NotImplementedError→501.
  무거운 모델은 첫 요청 lazy(전부 warm-load 안 함 → OOM 회피).
- **TDD**: `test_server.py` 9 tests(TestClient + `gate.generate` 모킹, GPU 0) → 전체 34 green.
- **실 SDXL e2e 실증**: HTTP POST → animagine 로드 → 768² PNG(888KB, 38.9s) → StaticFiles 200,
  프롬프트 충실(절벽 위 기사). 라이브 게이트: 비상업 모델 상업모드 → **403 차단 실작동**.
- README 로드맵 ⑤ ✅, 3계층 표기 갱신, HTTP 사용법 추가.

## ③ 갭1 해소 — 공통 discovery 규약 `GET /api/capabilities` (gen_gate `bc55eef` + voice_lab `58fecb0`)

> dogfood 가 찾은 갭1 즉시 공략. additive·비파괴(기존 엔드포인트 유지) → 비례성상 1-agent 직접.

- **공통 envelope(양쪽 동일)**: `{service, unit_param, modalities, units:[{id,modality,commercial,label}]}`
  - `unit_param`: `/api/generate` 에서 단위를 선택하는 payload 필드(gen_gate=`model`, voice_lab=`primary`).
    오케스트레이터가 `payload[unit_param]=unit.id` 로 *서비스 내부 모르고* generate 조립.
  - **등급 정규화**: gen_gate `commercial` / voice_lab `cc0` → 둘 다 `commercial` 로 통일.
- **gen_gate**: `server.py` +`/api/capabilities`, `test_server.py` +2 tests → 전체 **36 green**.
- **voice_lab**: `gpt_sovits_lab/server.py` +`/api/capabilities`(단위=화자 69, 상업안전 19).
  사용자 상주 서버(8777, 3일째) **정확한 기동 명령으로 재시작** → 라이브 검증(즉시 기동, 200).
- **라이브 전 루프 실증**: 균일 `discover(service)` → 양쪽 동일 경로·envelope.
  **하드코딩 0** — caps.unit_param + modality 만으로 generate payload 자동 조립
  (`{model:...,prompt:...}` / `{primary:...,text:...}`). discover→자동조립→생성 동시 호출, 양쪽 실 산출.
- **닫힌 갭**: 갭1(discovery 미정렬) + 갭3 완화(레지스트리 부재 → caps 가 단위·등급·필드 자체 공급).
