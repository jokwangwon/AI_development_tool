## ⑤ 2D 근본 품질 — 사용자 pivot

사용자 "2D부터 수정 — 어색한 선·불분명한 오브젝트". 클로즈업 진단: 소프트 선·온통 핑크(색 분리 부족)·장신구 임의/흐릿. **디자인 스펙 확정**(골드 티아라·빨강 리본·화이트 드레스·하트 참·타이즈, 명시 오브젝트+색 대비) → 재생성으로 오브젝트 명료화 성공.

### ⑤-a 선 품질 = 해상도 문제 (gen_gate hires-fix `a03dbcc`)
확대 시 선 불안정 = **모델/튜닝 아니라 1024 해상도 한계**(1024 vs 1280 vs hires-fix 비교 검증). **hires-fix 구현**: base(size) 생성 → 업스케일 → img2img 저-denoise 리파인(`_get_img2img` from_pipe, VRAM 0). 안정 구도 + 선 또렷 + SDXL native 아티팩트 회피. 73 passed.

### ⑤-b 오브젝트 의미/병합 = compositional 한계 (gen_gate inpaint `ea52250`)
"리본 중심 별vs매듭, 프릴 끊김/병합" = **text2img 즉흥생성의 구성 한계**(해상도로 안 잡힘). **inpaint 구현**(`inpaint()`, 마스크 영역만 재생성, 페더 블렌딩). 가슴 리본 별→둥근 중심 국소 수정. ⚠️ stochastic이라 반복 필요 — **근본은 캐릭터 정의/고정**임을 확인.
