## Part A — 진단 + 방향 확정 (brief → 승인)

- **문제(직전 Part R 사용자 지적)**: 입 보컬 타일(scale 0.001→1.0)을 닫힌 입 위에
  scale-grow 합성할 뿐, 주변 얼굴 메시(턱·볼·입술 피부)는 무연동 → 입 타일이 "붙었다
  떼였다" 이질감.
- **정찰**: inox2d_poc r7 구조 확인.
  - Face는 **이미 grid mesh**(uuid 1005)로 blink lid deform을 싣고 있음 → deform 용량 有.
  - **`deform_binding_unit(node, verts, field)`** = unit 파라미터가 per-vertex deform
    필드를 구동하는 패턴이 이미 검증됨(blink·hair-sway·yaw 전부 이 메커니즘).
  - 렌더러는 프레임당 활성 모음 1개를 `amount*gain`으로 set, 나머지 4개 0.
- **두 방향 비교**: ① 얼굴 메시 연동(검증 deform 재사용, 신규 자산 0, GPU-light, 단일
  변수) vs ② LoRA "입 벌린 얼굴 전체" 크로스페이드(정체성 드리프트·GPU 무거움).
  → **① 채택**. brief 사용자 승인.

## Part B — 구현 r8 (단일 변수: jaw-drop 연동)

- **`make_aveline_live2d_r8.rs`**(r7 복제 + 추가):
  - `jaw_drop_field(px_verts, drop_px)` 신규: 입선(y=690) **아래** 정점만 하강, 턱끝
    (y=835) peak, 목 앞(y=930)에서 taper(목 안 끌림), 수평 코사인 벨(±235px), 미세
    외측 widen. 상부 얼굴(코·눈·윗입술)은 pinned. hair-sway "거리 가중 deform"과 동형.
  - 5개 모음 파라미터(MouthA/I/U/E/O) **각각**에 Face(1005)·Head(1003) jaw-drop
    deform 바인딩 추가(`deform_binding_unit` 재사용). blink가 Face+Head 둘 다 묶는
    선례 답습(턱 silhouette coherent). 모음별 jaw 스케일 a=1.0·i=0.45·u=0.5·e=0.6·
    o=0.85(얇은 i/u는 턱 적게). `JAW_DROP_PX` env(기본 26).
  - 그 외 일체 r7 그대로(입 타일·팔·머리·뿔·날개·yaw·blink·hair).
- **`render_mouth_sheet.rs`** 신규: 단일 모음 파라미터 구동 before/after QA 시트 렌더러
  (나머지 파라미터 rest로 고정 → 변수 격리). Cargo.toml에 bin 2개 등록.
- **계산적 검증**: round8.inp 생성 + self cross-check PASS(21 텍스처·9 파라미터 1.0
  구동, 패닉 0). r7 vs r8 diff: **MouthA=0 → 완전 동일(diff 0=rest 부작용 0)**,
  MouthA=1.0 → r8가 하관을 행 272→474(~200px)까지 하강(입 타일 247~307 너머 확장).
