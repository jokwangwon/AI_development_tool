## 아크 2 — 메시 디포메이션 전환 (r13, 핵심 성과)

- 사용자 "**입이 연속적이지 않음, 각자 따로 이미지 재생되는 느낌, 이전 입술 잔상**" —
  ⭐ **정확**: 이미지 교체는 본질적으로 불연속. **튜닝으로 못 잡음**.
- **deep-research**(103 에이전트, 공식 docs.live2d.com): 프로 Live2D 입 = **메시 연속
  변형**(이미지 교체 ❌). `ParamMouthOpenY`(0닫힘~1열림)+`ParamMouthForm`(-1~+1) 2개
  직교 파라미터, 키폼 보간. **3겹 아트**(윗입술/아랫입술/내부, 내부는 입술 뒤 레이어로
  가려짐, 페이드 아님). 내부 1치수 크게+입술선 피부채움. 머리/눈도 동일(ParamAngleX/Y/Z).
- **사용자 선택 = 메시 디포메이션 재설계 + "실제 버튜버 리깅 찾아 적용"**.
- ⭐ **단일 텍스처 squash 실패**: 벌린 입을 메시로 닫으면 혀/치아 **smear**(뭉개짐).
  버그2 발견=**inox2d가 inverse deform 바인딩(field@0,zero@1) 미작동** → base mesh를
  squash로 베이크+정상 바인딩 우회. 그래도 squash=smear → 폐기.
- ⭐ **3겹 방식 채택**(조사대로): **윗입술/아랫입술(불투명, base 일러서 분리)+cavity(와이드
  inpaint, 입술 뒤)**. Python 미리보기로 **rest=깔끔한 닫힘**(불투명 입술이 cavity 가림)
  검증 → rust 리그(`make_aveline_live2d_r13.rs`). MouthOpenY가 입술 평행이동→갈라져 reveal.
  EMA 스무딩(`render_aveline_talking_r13.rs`). **연속성 달성**(v12).
- 사용자 "**턱이 블록째 떨어져 분리**" → 평행이동 대신 **grid+lip_part_field deform**
  (입술선 움직이고 경계는 얼굴에 glued, 페이드). 턱 분리 해소(v13).
- 사용자 "**하관만 따로 노는 느낌**" → **얼굴(Face/Head)에 jaw-drop deform 연동**(하관
  전체가 입과 함께). 단일 param 다중 deform 패닉=필드 합산으로 해결. cavity grid화(v14).
